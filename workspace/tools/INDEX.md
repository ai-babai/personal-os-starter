# Инструменты

Внешние инструменты пока не подключены этой установкой.
Локальное чтение/запись и другие возможности зависят от текущего клиента
и его прав; их наличие проверяется фактически.

Для новой возможности создай `tools/<capability>/README.md` по
[форме](../docs/templates/tool.md), добавь сюда маршрут и статус.
Процедура живёт здесь, код — в своём репозитории, runtime — в месте установки.
Результаты инструмента сохраняй в области задачи, а не рядом с его инструкцией.

Не создавай отдельный skill для каждой инструкции. Готовый полезный skill
можно установить отдельно, сохранив источник и лицензию; [каталог](../skills/INDEX.md).
