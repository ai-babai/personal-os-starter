# Заметки

Здесь можно хранить записи в удобном тебе порядке. Темы и подпапки добавляй,
когда они пригодятся. После сохранения агент даст ссылку на конкретную запись.

Это твои записи. Правила и решения по проектам агент хранит там, где они
применяются, а свою рабочую память ведёт отдельно в `system/agent/memory.md`.
