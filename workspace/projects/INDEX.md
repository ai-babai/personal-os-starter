# Проекты пользователя

Здесь личные и рабочие проекты пользователя, с кодом и без него.
Пока проектов нет. Для первого проекта создай `projects/<project>/INDEX.md`
по [форме](../system/docs/templates/project.md) и добавь сюда ссылку с назначением.
Формат и предел объёма заданы формой. Подробные решения и проверки храни
в материалах задачи, в карте оставляй маршрут к ним.

Если у проекта есть код, он остаётся в отдельном репозитории; запиши его
фактический путь в карте проекта.
