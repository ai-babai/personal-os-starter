# Проекты

Пока проектов нет. Для первого проекта создай `projects/<project>/INDEX.md`
по [форме](../docs/templates/project.md) и добавь сюда ссылку с назначением.
Там же храни точку продолжения и решения, раскрывая отдельные файлы по росту.

Код остаётся в `{{CODE_ROOT}}`, в отдельном репозитории проекта.
Личная законченная работа или знание без кода может жить в `personal/`.
