# Personal OS

Личная папка для совместной работы владельца и агента.

**Агент, начни с [AGENTS.md](AGENTS.md) и
[порядка старта](system/agent/BOOTSTRAP.md).** Они задают маршрут и правила сессии.
При первом входе проверь локальную среду; при продолжении используй существующий
профиль и сохранённое состояние, не запускай знакомство заново.

[Профиль](personal/profile.md) и [предпочтения](personal/preferences.md)
содержат подтверждённые ответы владельца. [Память](system/agent/memory.md) помогает
найти незавершённую работу. Код проектов хранится отдельно, здесь — знания и ссылки.

| Что нужно | Где искать |
|---|---|
| Личные материалы | [personal/INDEX.md](personal/INDEX.md) |
| Задачи и проекты | [projects/INDEX.md](projects/INDEX.md) |
| Работа агента, инструменты и правила | [system/INDEX.md](system/INDEX.md) |

Три папки и их служебные документы создаются при установке. Тематические
разделы, конкретные проекты, инструменты и навыки появляются по задачам;
их карты подсказывают место. Карты хранят маршруты, состояние — у своей задачи.
