# Personal OS

Личная папка для совместной работы пользователя и агента: знания и предпочтения
пользователя, материалы его проектов и задач, роль и память агента между сессиями.
Код проектов хранится в отдельных репозиториях; здесь остаются знания и ссылки на него.

[Карта знаний — INDEX.md](INDEX.md) · [Правила агента — AGENTS.md](AGENTS.md)

Агент начинает с карты и правил, затем открывает только нужную область.
При первом входе настраивается локальная среда; при продолжении используются
существующий профиль пользователя и сохранённое состояние задач.
Новые разделы появляются по задачам.
