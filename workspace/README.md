# Personal OS

Личная папка для совместной работы владельца и агента: знания, предпочтения,
материалы задач и продолжение работы между сессиями. Код проектов хранится
в отдельных репозиториях; здесь остаются знания и ссылки на него.

[Карта знаний — INDEX.md](INDEX.md) · [Правила агента — AGENTS.md](AGENTS.md)

Агент начинает с карты и правил, затем открывает только нужную область.
При первом входе настраивается локальная среда; при продолжении используются
существующий профиль и сохранённое состояние. Новые разделы появляются по задачам.
