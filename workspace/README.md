# Personal OS

Личная папка для совместной работы с агентом. Начни с [карты](INDEX.md).

Открой эту папку в BB или другом агентском клиенте и напиши:

> Прочитай INDEX.md, AGENTS.md и agent/BOOTSTRAP.md.
> Составь локальный AGENTS.md: укажи фактическую ОС, корень этой Personal OS
> и используемую оболочку, сохрани существующие правила.
> Познакомься со мной и заполни профиль и предпочтения по моим ответам.
> Начнём с одной полезной задачи.

[Профиль](personal/profile.md) и [предпочтения](personal/preferences.md)
заполняются при знакомстве. [Память](agent/memory.md) помогает следующему чату
найти незавершённую работу. Код проектов хранится отдельно, здесь — знания и ссылки.
