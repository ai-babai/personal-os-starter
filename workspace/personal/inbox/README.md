# Входящие

Сохраняй сюда короткие входящие записи по поручению владельца. При разборе
переноси в тематическую область и добавляй ссылку в её карту. Не делай массовый
импорт файлов и сообщений без отдельного согласования. Сырые быстрые записи
могут не иметь метаданных до оформления в долговечную заметку.
