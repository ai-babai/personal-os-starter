# Входящие

Сохраняй сюда короткие записи, которые владелец поручил оставить во входящих
до разбора. Если это папка свободных заметок по [корневой карте](../../INDEX.md),
сохраняй здесь и их.
Перед записью или разбором примени [рабочие правила](../../system/docs/WORKING-RULES.md#документы).
Массовый импорт файлов и сообщений требует отдельного согласования.
