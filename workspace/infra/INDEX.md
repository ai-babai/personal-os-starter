# Инфраструктура

Устройства и сервисы пока не зарегистрированы. Ничего не развёрнуто этой установкой.
Для разрешённого устройства/сервиса добавь карту: назначение, владелец,
размещение, инструкция диагностики, границы изменений и дата проверки.

Read-only проверка может обнаружить остановленный сервис. Запиши факт;
не запускай его автоматически. Реальные credentials хранятся вне OS,
а inventory содержит только необходимые несекретные ссылки.
