# Навыки

Сначала ищи подходящий навык в действующем клиенте и области задачи.
Комплект не устанавливает навыки заранее. Выбранный переносимый пакет сохраняй
в `system/skills/<name>/` с исходными ресурсами, лицензией и происхождением;
добавь маршрут сюда. Системные и plugin-managed пакеты оставляй установщику.

Собственная процедура живёт в `system/tools/`. Если для неё нужен skill,
создай только условие применения и ссылку, без второго алгоритма или кода.
Пример содержимого `system/skills/export-document/SKILL.md` (не установлен):

```markdown
---
name: export-document
description: >-
  Экспорт документа: применять, когда просят подготовить документ к выдаче.
---
Прочитай [процедуру](../../tools/document-export/README.md) и выполни её.
```

Подставь существующую процедуру. Если доступен штатный загрузчик, проверь формат;
не устанавливай runtime ради проверки. Автоматическое обнаружение зависит от
клиента: при необходимости добавь локальный вход к каноническому пакету.
Наличие файла, загрузка текущим клиентом и обнаружение новой сессией — разные
проверки. Непроверенное так и обозначь; явное чтение инструкции остаётся доступным.
