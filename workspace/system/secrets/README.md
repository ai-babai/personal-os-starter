# Секреты

Папка `system/secrets/` предназначена для правил обращения с секретами,
а не для хранения ключей и токенов.

Предлагаемый вариант — хранить значения вне Personal OS и Git-репозиториев:
в менеджере паролей, системном хранилище или отдельном защищённом каталоге.
Это уменьшает риск случайного включения ключей в Git, индексацию и синхронизацию
базы знаний. Конкретный способ хранения и безопасного ввода выбирает владелец
при первой интеграции с учётом своей среды; шаблон не настраивает хранилище заранее.

Значения, OAuth/cookies, private keys и экспорты менеджера паролей не помещать
в OS, Git или индексируемый vault.

Различай личные секреты человека и рабочие credentials разрешённой задачи.
Агент не читает значения в свой контекст; разрешённый runtime использует их
через безопасный ввод/ссылку. Не угадывай пути, не печатай содержимое и не делай
symlink в vault. Доступность credentials не даёт бюджет и полномочия операции.

`.gitignore` не является контролем доступа. На общем UID нужен реальный sandbox;
папка с mode 0700 не отделяет агента от человека того же пользователя.
