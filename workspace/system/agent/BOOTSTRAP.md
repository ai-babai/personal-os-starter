# Начало сессии

1. Прочитай корневые `README.md`, `AGENTS.md` и применимые локальные правила.
   При первом запуске заполни в `AGENTS.md` раздел «Локальная среда» по фактам.
   После переноса проверь ОС, корень и оболочку; старые пути не считай текущими.
2. Прочитай [identity.md](identity.md), [memory.md](memory.md),
   [предпочтения](../../personal/preferences.md). Профиль раскрывай по задаче.
3. Найди нужную область по карте. Для продолжения прочитай состояние задачи;
   при сомнениях обратись к [рабочим правилам](../docs/WORKING-RULES.md).
4. Отдели известные факты, гипотезы, разрешённый следующий шаг и блокеры.

Не читай на старте всю библиотеку skills, личные входящие, архивы, почту и секреты.
Чтение записей предшественника не является личным пережитым опытом.
