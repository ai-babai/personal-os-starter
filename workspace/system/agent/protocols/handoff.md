# Передача работы

В материалах задачи сохранить:

- что было поручено и какие границы действовали;
- сам результат, нужный следующей сессии: полный черновик, решение или план,
  либо ссылка на сохранённый артефакт; статус «черновик готов» не заменяет текст;
- важные для продолжения проверки и неизвестное — по [рабочим правилам](../../docs/WORKING-RULES.md);
- конкретный следующий шаг и блокеры;
- какие разрешения уже даны и для чего нужно новое решение владельца.

Подробности остаются за ссылками из карты; сама карта соблюдает
[короткую форму](../../docs/templates/project.md).

Не сохранять каждую мысль из обсуждения; учитывать просьбы не сохранять
и ограничения чувствительных данных. Если задача завершена, так и отметить;
не придумывать следующий проект.
При незавершённой работе добавить короткую ссылку в `system/agent/memory.md`.
Не копировать полную переписку и не переносить секреты. Сохранённый план сам
по себе не разрешает его исполнять: проверять исходные полномочия.
