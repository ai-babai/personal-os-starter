# Результат и продолжение работы

Сохраняй артефакты, которые предполагает задача: документ, код, файл или другой
запрошенный материал. Если разговор изменил существующую задачу, обнови её
материалы: принятое решение, состояние или следующий шаг. Обычное обсуждение
и текст для ответа в чате могут оставаться в чате; сама просьба составить текст
не означает обязательного создания файла.

Для сохранённой задачи оставь только нужное продолжению:

- сам артефакт или ссылку на него; статус «готово» не заменяет ожидаемый файл;
- важные проверки и неизвестное — по [рабочим правилам](../../docs/WORKING-RULES.md);
- следующий шаг и действующие границы, если работа продолжается.

Короткому результату достаточно раздела в существующем документе. Карта хранит
маршрут к нему и соблюдает [короткую форму](../../docs/templates/project.md).
При незавершённой работе добавь нужную ссылку в `system/agent/memory.md`.

Если для продолжения полезны подробности разговора, в существующий документ
задачи добавь одну строку: «Обсуждение: клиент · ссылка или ID сессии — о чём».
Используй фактический идентификатор; не выдумывай ссылку. Для чтения истории
нужен доступ к соответствующему клиенту. Отдельный журнал сессий не требуется.

Не копируй полную переписку и не создавай документ только ради разговора.
Учитывай просьбы не сохранять и ограничения чувствительных данных; не переноси
секреты. Черновик остаётся черновиком, сохранённый план не разрешает его исполнять.
Завершённую задачу отметь завершённой, не придумывай следующий проект.
