# Временная работа

Только временные файлы текущей задачи. Долговечный результат перенеси в область
владельца задачи. Содержимое кроме этой инструкции исключено из Git.
Не храни здесь единственную копию ценных данных, секреты или тяжёлые модели.
Удаляй только собственные временные файлы после проверки результата.
