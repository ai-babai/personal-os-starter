# Работа с публичным шаблоном

Начни с [INDEX.md](INDEX.md). Это исходный публичный комплект, а не личная OS.

- Для установки следуй [поручению](onboarding/AGENT_HANDOFF.md) и [установке](docs/INSTALL.md).
- Личные ответы, пути, имена, память, токены и результаты установки сохраняй
  вне публикуемого содержимого. `local/` игнорируется, но не является защитой доступа.
- Никогда не персонализируй `workspace/`: это нейтральные исходники для всех людей.
- Не копируй исходную приватную OS или её Git-историю. Каждый публичный файл
  должен быть отдельно пригоден к распространению.
- Не устанавливай коннекторы, не меняй глобальные настройки и не подключай аккаунты
  только потому, что выполняется установка ядра. Сначала выбери нужную задачу.
- Один источник каждого правила; карты ссылаются на владельца знания.
- Не добавляй постоянные тесты/CI без согласования владельца проекта.
  Временные проверки установщика и ссылок можно выполнять вне репозитория.
- Изменения не должны перезаписывать данные существующей OS. Установщик создаёт
  только новую установку; обновление существующей выполняется отдельно через diff.
- Перед публикацией проверь весь Git tree и историю на приватные данные.

Правила сгенерированной OS находятся в [workspace/AGENTS.md](workspace/AGENTS.md).
Они становятся действующими внутри новой установки, а не в репозитории шаблона.
