# Работа с публичным шаблоном

Начни с [INDEX.md](INDEX.md). Это публичный комплект для разных людей.

- Для развёртывания следуй [короткому поручению](onboarding/AGENT_HANDOFF.md).
- `workspace/` — готовые нейтральные документы. Их содержимое переносят в выбранный
  владельцем корень. Имя папки, букву диска и операционную систему не фиксируй заранее.
  Локальный `AGENTS.md` агент составляет после осмотра среды; исходник остаётся общим.
- Минимализм — принцип комплекта: достаточный текст и существующие возможности
  клиента. Любая новая обязательная программа требует реальной необходимости.
- Сохраняй простой вход: папка, агент, знакомство, первая задача.
  Базовый запуск должен работать обычным копированием документов. Автоматизация
  допустима как необязательное удобство по реальной задаче, без зависимости от неё.
- Не копируй приватную OS, её историю, аккаунты и токены в публичный комплект.
- При изменениях сохраняй один источник правила и рабочие относительные ссылки.
- Не перезаписывай существующие личные установки; обновляй выбранные документы
  с учётом их содержимого и разрешений владельца.
- Не добавляй постоянные тесты/CI без согласования владельца проекта.
  Ссылки и копирование можно проверить во временной папке вне репозитория.
- Перед публикацией проверь diff на личные сведения и секреты.

Правила личной OS находятся в [workspace/AGENTS.md](workspace/AGENTS.md).
