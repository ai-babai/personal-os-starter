# Проверка 0.1.0

Проверка 5 ноября 2026: macOS, Python 3.13.2, отдельные временные каталоги.
Временные проверки не входят в распространяемый комплект. Пользовательская
команда `check` входит в продукт как диагностика файлового ядра.

Проверено:

- `init --dry-run` не создаёт дерево; `init` и `check` работают на новой установке.
- Unicode, пробелы в путях и часовой пояс `Europe/Berlin` корректно подставляются.
- На POSIX все созданные каталоги имеют mode 0700, файлы — 0600.
- Повторный `init`, существующий пустой каталог и symlink-цель отвергаются;
  байты существующей установки сохраняются.
- Пересечение корня OS с кодом/шаблоном, лишние поля JSON, неверный JSON,
  многострочные значения и неизвестный часовой пояс отвергаются.
- `check` обнаруживает отсутствие файла ядра, broken link, остаточный placeholder
  и symlink вместо файла ядра. Личные добавленные заметки не обходит.
- Две установки с разными владельцами получают независимые профили и чистую память.
  Git-история и remote не создаются.
- Стартовая карта ведёт к профилю, предпочтениям, identity, памяти, проектам
  и честному статусу неподключённых инструментов.
- Markdown-метаданные и относительные ссылки публичного комплекта проверены;
  выполнен поиск известных приватных идентификаторов и форматов credentials.

Не проверено в этой поставке: отдельная установка на Linux/Windows, Python 3.9,
автоматическая загрузка инструкций всеми агентскими клиентами, поведение новой
модели, реальные коннекторы, восстановление пользовательского backup и системная
изоляция семейных аккаунтов. Стандартная библиотека и отсутствие shell-команд
делают перенос реалистичным, но не заменяют фактическую проверку новой среды.

Проверка навигации на диске не является запуском второго агентского чата.
