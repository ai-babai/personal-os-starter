# Границы данных

Публичен только нейтральный комплект. Личные профили, переписка, документы,
история задач, inventory реальных машин и конфиги с адресами — в отдельной OS.
Токены, пароли, cookies, OAuth и private keys — вне OS во внешнем защищённом store.
Не делайте symlink из индексируемого vault на секретные значения.

`.gitignore` снижает вероятность ошибки, но не защищает от `git add -f`,
уже отслеживаемого файла, публикации истории, индексации или облачной синхронизации.
Приватный Git-репозиторий тоже не является хранилищем секретных значений.
Для личной OS создавайте новую историю и приватный remote только по запросу.
Не публикуйте заполненный GitHub template/fork с личными данными.

Сканер секретов не доказывает отсутствие личных данных. Перед любой публикацией
просмотрите весь diff и историю, имена/пути/метаданные/вложения. При утечке ключа
отзывайте его; удалить строку из последнего коммита недостаточно.

## Семья и помощь другим

У каждого человека отдельные данные и аккаунты. Помощник получает только
согласованный доступ; администрирование компьютера не равно разрешению читать
переписку. Для общей семейной информации отдельно согласуйте общий каталог,
состав участников и правила. Не объединяйте личные памяти автоматически.
Права 0700/0600 на POSIX защищают от других обычных пользователей, но не от
агента, работающего с тем же UID. Нужны реальные границы sandbox/учётных записей.
На Windows настройте ACL отдельно; chmod не заменяет их.

## Резервные копии и восстановление

Выберите защищённое место и срок хранения вместе с владельцем. Сохраняйте OS
и внешний store секретов отдельно; credentials восстановления держит владелец.
Не включайте резервное копирование/облачную синхронизацию без согласования.
Проверьте восстановление в новый приватный каталог без переключения работающих
сервисов. После восстановления проверьте пути, permissions и клиентский вход;
токены и OAuth восстанавливайте штатно, а не через перенос чужой сессии.

Перед отправкой содержимого агенту учитывайте его провайдера и политику данных:
локальная папка не гарантирует, что прочитанное останется на компьютере.
