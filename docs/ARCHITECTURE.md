# Устройство

Personal OS — обычные файлы на диске. Клиент и модель могут меняться;
знания, решения и точки продолжения остаются у владельца.

`workspace/` в этом репозитории — чистая готовая папка. Её содержимое копируют
в выбранное владельцем место и заполняют во время знакомства. Корень может
находиться где угодно, в том числе прямо на диске. Каждый человек получает свою OS.

Фактическую ОС хоста, полный корень и оболочку агент записывает в локальный
`AGENTS.md`. В публичном шаблоне эти значения неизвестны. При переносе меняется
описание локальной среды, а относительные ссылки и знания остаются пригодными.
Остальные папки на диске не включаются в OS только из-за соседства.

## Один источник каждого факта

- Профиль — `personal/profile.md`, предпочтения общения — `personal/preferences.md`.
- Рабочая роль агента — `system/agent/identity.md`, короткая память — `system/agent/memory.md`.
- Текущее состояние задачи — в её проекте. Память ссылается на него.
- Процедура инструмента — в `system/tools/<capability>/README.md`.
- Исходный код — в отдельном репозитории; в OS хранится ссылка на него.

## Загрузка по необходимости

Агент начинает с `README.md`, `AGENTS.md`, `system/agent/BOOTSTRAP.md`, затем открывает
нужную область и документ задачи. Полную память, входящие, переписку и библиотеку
навыков читать на каждом старте не нужно. Новые разделы появляются из реальных задач.

## Переносимость

Ядро состоит из UTF-8 Markdown и относительных ссылок. Достаточно скопировать
папку и открыть её в клиенте с доступом к файлам. После переноса нужно проверить
только добавленные человеком абсолютные пути и фактический доступ нового клиента.
Автоматическое чтение инструкций и подключённые инструменты проверяются отдельно.
