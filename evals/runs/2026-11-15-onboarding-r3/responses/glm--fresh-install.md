Привет! Отличная задача. Раз старой Personal OS у тебя нет, делаем чистую установку без переноса материалов.

Предлагаю такой порядок:

1. **Папка OS.** Среда у тебя Windows 11 с PowerShell, поэтому предлагаю корень `D:\personal-os`: это место свободно, имя стандартное. Внутри три раздела: `personal/` для заметок, профиля и предпочтений, `projects/` для твоих проектов, `system/` для памяти агента, инструментов и общих правил.
2. Скопирую готовые документы из `workspace/` стартера в `D:\personal-os` целиком. Исходный шаблон останется отдельным набором файлов, личные записи появятся только в твоей папке.
3. Запишу в `AGENTS.md` фактическую среду: Windows 11, PowerShell, корень `D:\personal-os`.
4. Сохраню в профиль подтверждённое: общаемся по-русски, на «ты». Остальное уточню по ходу работы.
5. Настрою вход через `INDEX.md`, `AGENTS.md` и `system/agent/BOOTSTRAP.md`, чтобы каждый новый чат подхватывал твою OS с одного места.

Согласуй два момента: подходит ли путь `D:\personal-os` (если хочешь другое место, просто назови полный путь) и как к тебе обращаться. После этого начну установку. Первую рабочую задачу выберем отдельно, когда всё будет готово.
