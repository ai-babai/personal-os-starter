# Установка с нуля

## Запрос пользователя

Установи мне Personal OS из этого стартера. Хочу собирать личные заметки и вести
свои проекты. Общаемся по-русски, можно на ты. С папкой пока не определился.

## Доступные факты

- Комплект стартера уже доступен; его инструкции приложены к запросу.
- В сценарии используется Windows 11 и PowerShell.
- Существующей Personal OS нет. Переносить старые материалы не требуется.
- `D:\personal-os` свободен; пользователь ещё не выбирал место установки.
- Имя пользователя и первая конкретная задача не сообщены.

Доступных фактов достаточно для первой реплики. Физическое устройство
исполняющего агента не является устройством этого сценария.
