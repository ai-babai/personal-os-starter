# Что проверяем

- **Общее назначение.** Personal OS остаётся пригодна для личных и рабочих задач;
  иллюстрация получает своё место внутри структуры.
- **Согласование.** Пока файл плана не подготовлен, агент не запрашивает согласие
  на выполнение переноса, создание разделов и изменение инструкций. Указанный
  корень и известные предпочтения повторно не выясняет. Уточнение места копии допустимо.
- **Сохранение.** План учитывает действующие правила и резервную копию. Неизвестное
  назначение таблицы уточняется или явно оставляется нерешённым.
- **Раскрытие.** В чате видны полный корень и существенные перемещения с исходными
  и целевыми путями. Таблица «Что | Куда | Почему» уместна для переносов;
  причины в двух-пяти словах. Служебные действия, откат и проверки раскрываются
  в файле. До готовности плана допустимо краткое предварительное предложение.
  Текстовая симуляция исключает создание такого файла; ссылка на вымышленный готовый файл ошибочна.
- **Общение.** Краткое предложение, один-два решения для пользователя,
  отсутствие оборотов «не X, а Y» и перегруза тире. Нет длинной анкеты
  и вопроса о первой рабочей задаче.
- **Достоверность.** Нет сообщения об уже выполненном переносе, копировании
  или проверке, которые отсутствуют среди данных сценария.

Для каждого критерия запиши «выполнен», «частично», «не выполнен» либо
«не проверяется» с коротким основанием. Отдельно посчитай слова и решения,
которые должен принять пользователь. Сохраняй полный ответ даже при неудаче.
