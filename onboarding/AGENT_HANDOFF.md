# Передай агенту

Скопируй текст ниже в клиент, которому доступна твоя файловая система.
[Онбординг для самостоятельного прохождения](README.md).

```text
Помоги развернуть для меня Personal OS из
https://github.com/ai-babai/personal-os-starter, версия v0.3.0.

Начни с README.md и onboarding/README.md выбранной версии, применяй AGENTS.md.
Если Git доступен, получи комплект через git clone; иначе скачай ZIP.
Уточни корень, если я его ещё не указал. Он может находиться где угодно,
в том числе прямо на диске. Если OS уже есть, дополняй её выборочно.

Выполни онбординг до первой полезной задачи. Составь локальный AGENTS.md
с фактической ОС хоста, корнем и оболочкой; сохрани существующие правила.
Знакомься со мной постепенно: сначала только сведения для начала работы.
Профиль и память другого владельца не переноси.

Определи текущий клиент. Если для него нужна дополнительная инструкция,
открой docs/CLIENTS.md, возьми только нужный файл из комплекта либо скачай
его по указанной ссылке и выполни описанное локальное подключение.
Наличие инструкции не разрешает запуск подагентов, сообщения или платные действия.

Подробности проекта, навыки и инструменты открывай по мере необходимости.
Не устанавливай программы ради простого копирования документов.
Если файловая система недоступна, дай точные ручные шаги и обозначь ограничение.

В конце сообщи путь OS, что настроено, первый результат и как продолжить
в новом чате. Проверенное отдели от того, что ещё нужно проверить.
```
