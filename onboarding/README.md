# Начать работу

[О проекте](../README.md) · [Поручение агенту](AGENT_HANDOFF.md) · [Инструкции клиентов](../docs/CLIENTS.md)

**Получить комплект → выбрать место → познакомиться → решить первую задачу.**

Нужен агентский клиент с доступом к файлам. Python и Node.js для стартера
не требуются. Для уже работающей OS в конце есть порядок выборочного обновления.

## 1. Получить комплект

### Через Git, если он установлен

В каталоге, где удобно хранить исходный шаблон, выполни:

```sh
git clone --branch v0.3.0 https://github.com/ai-babai/personal-os-starter.git
```

Команда подходит для PowerShell и обычных терминалов macOS/Linux.
Она создаёт папку `personal-os-starter` с выбранной версией комплекта.
Git удобен, если хочешь смотреть историю и сравнивать будущие изменения.

### Через ZIP

[Скачать v0.3.0.zip](https://github.com/ai-babai/personal-os-starter/archive/refs/tags/v0.3.0.zip)
и распаковать штатными средствами системы.

**В ZIP тот же комплект документов, что в Git, без истории `.git`.**
Внутри: `workspace/`, онбординг, общие пояснения и необязательные инструкции
клиентов. Это исходный шаблон; личная рабочая область создаётся следующим шагом.

Оба способа дают одинаковые файлы версии `v0.3.0`. Дальнейшие шаги общие.

## 2. Выбрать место для личной OS

Выбери корень сам или укажи его агенту. Имя папки и буква диска любые:
например, `D:\`, `D:\PersonalOS` или удобный каталог на Mac/Linux.
Скопируй туда **содержимое `workspace/`**, включая `.gitignore` и `LICENSE`.

Шаблон и заполненная OS должны оставаться разными наборами файлов.
Личные ответы записываются в выбранный корень; исходный репозиторий остаётся
нейтральным. Не копируй его `.git` в свою OS и не отправляй личные данные
в публичный remote шаблона.

Если в выбранном месте уже есть файлы, агент сначала осматривает совпадения,
добавляет недостающее и сохраняет существующие инструкции и заметки.
Соседние папки на диске автоматически не включаются в OS.

## 3. Познакомиться с агентом

Открой выбранный корень в своём клиенте или дай агенту доступ к нему. Отправь:

```text
Прочитай INDEX.md, AGENTS.md и agent/BOOTSTRAP.md в корне моей Personal OS.
Составь локальный AGENTS.md по шаблону: укажи фактическую ОС хоста,
полный корень OS и используемую оболочку. Сохрани существующие правила.
Спроси, как ко мне обращаться, какой язык и стиль общения удобны
и какую первую задачу я хочу решить. Запиши только подтверждённые ответы
в personal/profile.md и personal/preferences.md.
Подробности обо мне, проектах и инструментах раскрывай по мере необходимости.
```

Начальные сведения о человеке короткие. Имя и стиль агента можно выбрать позже.
При удалённой работе ОС хоста с файлами может отличаться от ОС устройства,
на котором открыт интерфейс; агент проверяет реальную среду.

### Если нужны особенности клиента

Агент определяет, какой клиент используется, и смотрит только соответствующий
пункт в [каталоге](../docs/CLIENTS.md). Например, для BB можно взять
[отдельную инструкцию](../clients/bb.md) из этого комплекта или скачать её
по ссылке из каталога. Порядок локального подключения описан в самой инструкции.
Остальные клиентские материалы читать и устанавливать не нужно.

## 4. Получить первый результат

Попроси сохранить полезную заметку, разобрать материал или продолжить проект.
Агент оставляет результат в нужной области, ссылку в её карте и точку продолжения.
В новом чате укажи тот же корень и попроси найти, на чём остановились.

Начало удалось, если агент нашёл реальные файлы, верно назвал профиль и среду
и смог продолжить задачу. Если новой сессии ещё не было, эта проверка впереди.

Дальше система растёт по работе: [подключения](../docs/INTEGRATIONS.md),
[устройство знаний](../docs/ARCHITECTURE.md), [приватность](../docs/PRIVACY.md).

<summary><strong>Если Personal OS уже работает</strong></summary>

Сначала прочитай её карту, локальные правила и актуальную память. Сравни
только нужные документы с новой версией шаблона. Переноси выбранные изменения,
сохраняя профиль, знания, решения и действующие клиентские настройки.
Не копируй пустой профиль или чистую память поверх заполненных файлов.

Инструкцию нового клиента можно добавить отдельно по каталогу. После переноса
на другой компьютер перепроверь раздел «Локальная среда» в `AGENTS.md`.
Само обновление шаблона не меняет существующую личную OS.

</details>
